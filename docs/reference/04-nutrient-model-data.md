# FoliarScript - Nutrient Threshold Model Data

Complete model containing optimal ranges for each crop/stage/nutrient combination.

## Model Structure

Each entry contains:
- `ranges.low` / `ranges.high`: Optimal range for nutrient level
- `hit`: Target value to reach when deficient
- `apply_assumption.concentrate`: Fertilizer concentration used in calculation
- `apply_assumption.rate`: Application rate used in calculation
- `apply_assumption.change_percentage`: Expected change percentage
